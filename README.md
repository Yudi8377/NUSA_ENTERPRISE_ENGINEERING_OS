# NUSA ENTERPRISE ENGINEERING OS

Enterprise Operating System + Engineering Intelligence Platform + Multi-Agent AI + Digital Twin.

## Delivery target
Controlled rollout from foundation to production across ERP, CRM, HRD/Payroll, Finance/Tax, Procurement/Asset, Project/Construction, CAD/BIM/SAP2000, Interior/AR/VR/MR, NUSA Voice, AI Governance, Self-Healing, Reporting and Forecasting.

## Architecture
- Next.js web control plane
- Supabase/Postgres for multi-tenant data, Auth, RLS, Storage and future pgvector/PostGIS
- Vercel AI SDK / AI Gateway for model routing and tool calling
- Local Windows Engineering Bridge for SAP2000 OAPI, AutoCAD/BricsCAD, Revit/SketchUp and licensed desktop software
- Evidence-first audit trail and human approval gates

## Status
Phase 0/1 foundation initialized. Yayasan Ngawi is the first pilot project seed. The dashboard is a product foundation, not a claim that engineering safety has been automatically certified.
