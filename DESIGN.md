# NUSA Design Constitution

Visual direction: dark engineering command center, calm green instrumentation, high information density without visual noise.

Interaction rules:
- Every destructive action requires explicit confirmation and audit event.
- Posted/audited records use void/reverse/archive instead of physical delete.
- Critical engineering outputs require human approval.
- Mobile navigation collapses to a drawer.
- Workflows expose Insert, Update, Save, Cancel, Search, Filter, Print, Export, Submit, Approve, Reject, History and Evidence where applicable.
- Indonesian is primary; technical English can be secondary.
