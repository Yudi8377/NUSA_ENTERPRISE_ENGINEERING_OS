# NUSA Parallel Build Contract

NUSA is developed as parallel workstreams sharing one governed platform contract.

## Parallel streams
- Core & tenant platform
- Knowledge / RAG / reasoning / memory
- AI orchestrator and agent permissions
- ERP: finance, CRM, HR, tax, procurement and asset
- Project / construction / QA / HSE
- Architecture / CAD / BIM / Pascal spatial engine
- Structural / SAP2000 / geotechnical / seismic
- QS / BOQ / RAB / cost control
- Interior / AR / VR / MR
- Field vision / evidence
- Voice / Indonesian language normalization
- Guardian / evaluator / security / self-healing
- Reporting / forecasting / integration

Every stream must produce code, schema, tests and evidence against the shared NUSA governance contract. A stream may be marked foundation/building/planned, but must not be presented as production-ready until its automated and manual release gates pass.
