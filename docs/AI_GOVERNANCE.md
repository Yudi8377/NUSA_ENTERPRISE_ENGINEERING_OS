# NUSA AI Governance

## Evidence-first
Every consequential result records intent, agent, provider/model, inputs, evidence references, output and approval state.

## Approval classes
Normal = informational/drafting. High = financial, compliance, procurement, project control. Critical = structural, seismic, foundation, HSE stop-work, final engineering approval.

Critical actions require explicit human approval.

## Local-first provider
Default provider is local Windows execution (Ollama/LM Studio or another approved local runtime). External model providers are optional and disabled by default for proprietary engineering data.

## Indonesian voice normalization
112 -> seratus dua belas
RW 04 -> RW nol empat
RT 07 -> RT nol tujuh
Decimal values and engineering units are normalized before speech.
