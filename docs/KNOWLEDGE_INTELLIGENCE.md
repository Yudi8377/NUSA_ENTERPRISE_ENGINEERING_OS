# NUSA Knowledge & Intelligence Foundation

## Purpose

NUSA is not initialized as a blank chatbot. From the first application build it has a governed knowledge and reasoning substrate.

Core loop:

**Intent → Specification → Policy → Knowledge → Agent → Execution → Observation → Evidence → Verification → Learning**

## Knowledge layers

1. **Core constitution** — system principles, safety boundaries and evidence rules.
2. **Domain knowledge** — architecture, structural, geotechnical, MEP, BIM, QS, construction, HSE, legal, finance, HR, procurement, AI, voice, spatial and interior.
3. **Authoritative sources** — standards, regulations, laws, manuals and controlled project sources with version/hash/provenance.
4. **Project knowledge** — drawings, models, specifications, decisions, assumptions, site evidence and revisions.
5. **Memory** — episodic, semantic, procedural, preference, project and lessons learned.
6. **Agent skills** — explicit capabilities and policy constraints per specialist agent.
7. **Reasoning runs** — auditable intent, context, assumptions, findings, recommendations, uncertainty, evidence and approval state.

## Intelligence behavior

NUSA must:
- retrieve relevant knowledge before high-value reasoning;
- prefer authoritative and current sources;
- separate facts, assumptions, recommendations and uncertainty;
- retain provenance;
- learn from verified project outcomes;
- avoid inventing missing engineering/site data;
- escalate critical decisions to human approval;
- use specialist agents instead of one generic model for every task.

## Indonesian-first intelligence

Language is contextual, not a translation layer. NUSA should understand Indonesian engineering terms, abbreviations, project vocabulary, numbers, dates and role terminology and preserve them consistently in text and voice.

## Production boundary

The knowledge tables are a foundation, not a claim that all Indonesian standards or regulations are already loaded. Standards must be ingested from controlled/authoritative sources with version, effective date, hash and provenance.

## Next intelligence layers

- model routing and evaluator;
- RAG with evidence citations;
